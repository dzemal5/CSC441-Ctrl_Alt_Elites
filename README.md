Travel Bucket List

## 4. Project description:
Our project is going to be a Travel Bucket List, that will allow users to explore travel destinations they would like to visit. Users will be able to view the pictures, descriptions and popular attractions of these destinations.

## 5. Two functional tabs:
Tab 1 will display travel destination options, with their names, pictures and descriptions that the user can look through. Tab 2 will display the specific information about whichever destination the user selects, such as popular attractions at this destination. 

## 6. Technology:
The Android App will let users explore travel destinations they would like to visit, as well as the details about them. The website will provide similar features, just through a web browser, and Supabase will be the backend that stores the information about the travel destinations.
